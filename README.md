# 魔女持久战

<p align="center">
  <img src="assets/witch-protracted-war.png" width="360" alt="魔女持久战图标">
</p>

一个面向创业者、经营者和战略分析者的 Codex Skill：把毛泽东《论持久战》的条件分析、阶段转换、“持久中的速决”、主动性与动员方法，转译为商业模式诊断、竞争战略、资源配置、行动战役和止损闸门。

它重点吸收美团在本地商业中的密度、规模与学习经验，以及去哪儿创始人庄辰超关于价格战终局、稀缺资源、集中投入和“回程船票”的公开方法；案例只作为可核验的类比，不宣称这些公司直接采用了《论持久战》。

## 能做什么

- 判断一个商业模式是否值得打持久战，以及时间站在哪一边
- 分别判断 PMF、单位经济、供给网络、品牌渠道和组织所处阶段
- 把长期目标拆成 1–3 个短周期、可判定、可止损的关键战役
- 建立单位经济、现金跑道与战役/业务/公司三级闸门
- 输出 30/90/365 天创业行动路线图
- 用美团、去哪儿、亚马逊案例做“可借鉴 / 不可照搬 / 迁移动作”分析

## 安装

将本仓库目录放入 Codex 的 skills 目录，保持目录名为 `witch-protracted-war`。技能的机器名遵循小写英文规范，界面展示名为“魔女持久战”。

调用示例：

```text
使用 $witch-protracted-war 分析我的社区养老 SaaS：我们有 12 家付费机构，月流失 3%，现金还能支持 10 个月。请判断现在该扩张、继续验证还是收缩，并给出 90 天战役和止损线。
```

```text
使用 $witch-protracted-war 复盘这次价格战。重点检查我们是否锁定了稀缺资源、补贴停止后份额能否守住，以及“回程船票”是否触发。
```

## 设计边界

- 军事术语仅用于结构化思考，不将用户、员工、商家或竞争者物化为敌人。
- 长期主义不等于无限烧钱；技能强制设置验证窗口、投入上限和退出动作。
- 大厂案例不能替代用户自己的数据和语境。
- 输出不构成投资、法律或财务专业意见。
