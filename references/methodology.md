# 《论持久战》到商业分析的方法论

## 使用原则

《论持久战》写于特定战争与历史语境。本技能只迁移其认识论与战略结构：从全体条件而非单一强弱出发、观察力量随时间变化、分阶段行动、在长期目标下组织短期可判定行动、依靠广泛参与并保留主动权。战争的政治与伦理结论不能直接类推到商业。

理论原文以求是网收录的《毛泽东选集》第二卷《论持久战》为主：https://www.qstheory.cn/books/2019-07/31/c_1119478087_9.htm

## 五个可迁移的核心

### 1. 从“全部相互关系”判断趋势

原文不是简单的“弱者熬久就赢”。它综合比较强弱、进步/退步、大小、多助/寡助等基本特点，并强调优势和劣势会因行动与环境而转化。

商业翻译：不要只看融资额、用户数或技术中的一项。判断竞争结构、客户价值、经济模型、资源约束、组织与生态如何相互作用，以及这些变量的变化率。

### 2. 三阶段是状态模型，不是日历

- **战略防御**：能力或模型未证实。目标是存活、学习、找到可守的局部优势。
- **战略相持**：核心模式部分成立，但胜负未定。目标是提高密度、效率、留存与组织重复性。
- **战略反攻**：增长引擎与单位经济可复制，关键资源和组织容量能够支持扩张。目标是集中资源放大已验证优势。

阶段不是按时间自动升级；若经济模型恶化、供应链失稳或法规变化，也可能退回上一阶段。产品、城市、渠道等不同战线可处于不同阶段。

### 3. “持久中的速决”是实验组合

原文区分整体战略的持久和局部战役的速决。商业翻译不是“所有事情都快”，而是把长期不确定性拆成短周期、单约束、可验收的战役。每场战役用有限投入换取知识或可持续资产，并以多个局部胜利改变整体条件。

### 4. 主动性、灵活性、计划性必须共存

- **主动性**：以客户价值和自身关键约束定节奏，不被竞品每次动作牵引。
- **灵活性**：保留现金、人才和技术预备队；快速重配可逆资源。
- **计划性**：预先定义目标、门槛和复盘节奏，同时根据新事实修改计划。

### 5. 动员的商业对应是价值交换

原文强调广泛动员和参与。在商业中，应翻译为用户、员工、供给方和伙伴愿意共同建设的机制。判断真实网络效应时，必须证明新增参与者提高了另一侧价值或降低了系统成本；规模本身不等于网络效应。

## 时间方程

分别列出下列变量的方向、速度、证据和拐点：

| 变量 | 典型问题 |
|---|---|
| 价值复利 | 数据、品牌、复购、密度或流程是否随使用增强？ |
| 学习速度 | 从假设到有效反馈需要多久？比对手快多少？ |
| 资源耗散 | 现金、人才、商誉、供给关系以多快速度消耗？ |
| 锁定/转换 | 胜利后是否留下稀缺资源、转换成本或习惯？ |
| 外部变化 | 技术、监管、渠道和宏观趋势对谁更有利？ |

可用判断式：

`战略耐久度 = 可用跑道 ÷ 完成关键验证所需时间`

`净优势变化 ≈ 能力复利 + 学习收益 + 外部顺风 − 现金耗散 − 组织损耗 − 对手反制`

这些是思考式，不是假装精确的财务公式。必须写清口径、数据和不确定性。

## 阶段门槛示例

以下仅用于选择指标，不提供通用数值：

| 战线 | 防御→相持 | 相持→反攻 |
|---|---|---|
| 产品市场匹配 | 目标细分出现稳定留存/复购 | 多批次、多个相近细分可重复 |
| 单位经济 | 贡献亏损有可证实改善路径 | 扩张后贡献仍为正且回收期可承受 |
| 供给/履约 | 核心场景可稳定交付 | 密度提升带来成本或体验优势 |
| 获客 | 找到至少一个有效渠道 | 渠道可规模化且边际 CAC 未失控 |
| 组织 | 创始团队可重复交付 | 新团队/新区域仍能复制流程 |

## 反机械套用检查

分析结束前回答：

1. 如果时间并不站在我方一边，什么证据最先出现？
2. 若不考虑竞争对手，客户是否仍愿意购买？
3. 每场胜利留下了什么持久资产？
4. 哪项假设一旦被否定就应退出？
5. 是否把“坚持”用来逃避沉没成本和身份压力？
